Небольшие веб-продукты [Алексея Имузова](https://github.com/aimuzov). Каждый — статичный сайт на [Astro](https://astro.build) с островами на [Svelte](https://svelte.dev), который по SSH деплоится на один сервер с [Caddy](https://caddyserver.com).

## Проекты

| Проект | Что это | Сайт |
| --- | --- | --- |
| [codenames](https://github.com/aimuzov-projects/codenames) | Настольная игра Codenames как офлайн-PWA: на одном устройстве или с телефона на телефон через WebRTC | [codenames.aimuzov.online](https://codenames.aimuzov.online) |
| [community-taplist](https://github.com/aimuzov-projects/community-taplist) | Цифровая доска кранов для крафтового бара | [taplist.aimuzov.online](https://taplist.aimuzov.online) |
| [prestige-logist](https://github.com/aimuzov-projects/prestige-logist) | Превращает поручение экспедитору (КНД 1110486) в заявку на перевозку груза (КНД 1110361) | [logist.aimuzov.online](https://logist.aimuzov.online) |
| [shkatova-psychologist](https://github.com/aimuzov-projects/shkatova-psychologist) | Сайт перинатального психолога Татьяны Шкатовой с ИИ-ассистентом для подготовки к первой встрече | [tatiana-shkatova.ru](https://tatiana-shkatova.ru) |

## Инфраструктура

[infra-template-site](https://github.com/aimuzov-projects/infra-template-site) — шаблон, с которого начинается каждый новый сайт: Prettier, oxlint, stylelint, `node --test`, воркфлоу проверок и деплоя по SSH.
